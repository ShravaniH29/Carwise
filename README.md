# Carwise

### Find the car that fits your life.

Carwise is a frontend-first car discovery experience designed to help people researching their next car move from browsing options to making a more informed shortlist.

Instead of treating car shopping as a list of specifications, Carwise brings vehicle discovery, guided preferences, detailed car pages, shortlisting and comparison into one responsive experience.

## Live Project

**[Explore Carwise](https://carwise-umber.vercel.app)**

## What You Can Do

- **Discover Cars** — Browse a curated collection of 12 cars and search by model, category or fuel details.
- **Find Your Fit** — Use guided discovery to narrow down options by budget, body type and fuel preference.
- **Explore Vehicle Details** — View individual car pages with image galleries, vehicle overviews and specifications.
- **Build a Shortlist** — Save cars and access your shortlist even after refreshing the browser.
- **Compare Options** — Select up to three cars and review their key information side by side.

## Run Locally

**Requirements:** Node.js and npm.

Clone the repository:

```bash
git clone https://github.com/ShravaniH29/Carwise.git
```

Navigate to the project:

```bash
cd Carwise
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Project Status & Data Disclaimer

Carwise is a portfolio MVP and product exploration. Vehicle information and price ranges are illustrative placeholders, not live automotive data.

The current version does not provide verified owner reviews, live dealer inventory or purchase transactions. Always verify vehicle specifications and prices with official sources before making a purchase decision.
